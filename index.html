1. Змінні

Змінна — це ім'я, яке вказує на значення. Через ім'я до значення можна звертатися далі в програмі.

1Створення

Окремої команди для створення немає. Змінна з'являється, коли їй уперше щось присвоюють знаком =.

name = "Yulia"
age = 28

print(name)
print(age)
Yulia 28

= тут не «дорівнює», а «поклади значення справа в ім'я зліва».

2Перезапис

Змінній можна присвоїти нове значення. Старе зникає.

score = 10
score = 25

print(score)
25

Нове значення можна рахувати зі старого:

score = 10
score = score + 5

print(score)
15

3Правила імен

  • Можна: літери, цифри, _.
  • Не можна починати з цифри: 2name — помилка.
  • Не можна пробіли й дефіси: user name, user-name — помилка.
  • Регістр важить: age і Age — дві різні змінні.
  • Не можна брати службові слова: if, for, class.

У Python заведено писати імена в стилі snake_case: малі літери, слова через підкреслення.

user_name = "Yulia"
total_price = 350

Пастка. Не називай змінні list, str, sum, input. Помилки не буде, але вбудована функція з таким іменем перестане працювати.

4Кілька змінних одразу

x, y = 10, 20
a = b = 0

print(x, y, a, b)
10 20 0 0

Обмін значень без третьої змінної:

x, y = y, x

print(x, y)
20 10

Коротка шпаргалка

ЗаписЗначення
x = 5створити або перезаписати змінну
x = x + 1збільшити на 1
a, b = 1, 2дві змінні за раз
a, b = b, aпоміняти місцями
snake_caseстиль імен у Python

2. Типи даних

Кожне значення має тип. Тип визначає, що з цим значенням можна робити.

1Чотири базові типи

ТипЩо цеПриклад
intціле число42, -7, 0
floatдробове число3.14, -0.5, 2.0
strрядок (текст)"hello", '42'
boolлогічне значенняTrue, False

Є ще None — «значення немає». Його повертає функція, яка нічого не повертає.

2Як дізнатися тип

print(type(42))
print(type(3.14))
print(type("42"))
print(type(True))
<class 'int'> <class 'float'> <class 'str'> <class 'bool'>

42 і "42" — різні речі. Перше число, друге текст із двох символів.

3Перетворення типів

print(int("5") + 1)
print(float("2.5"))
print(str(10) + "0")
print(int(3.9))
6 2.5 100 3

int() з дробового числа не округлює, а відкидає дробову частину. Для округлення є round().

Не кожен рядок можна перетворити на число:

int("hello")
int("3.7")
ValueError

"3.7" спершу треба перетворити через float(), а вже потім через int().

4Що вважається False

bool() перетворює будь-яке значення на True або False. «Порожні» значення дають False:

print(bool(0))
print(bool(""))
print(bool([]))
print(bool(None))

print(bool(5))
print(bool("0"))
False False False False True True

"0" — непорожній рядок, тому True.

5Дробові числа неточні

print(0.1 + 0.2)
0.30000000000000004

Це не помилка Python, так комп'ютер зберігає дроби. Для показу користувачу округлюй: round(0.1 + 0.2, 2).

4. Оператори

Оператори — це знаки дій: порахувати, порівняти, поєднати умови.

1Арифметичні

print(7 + 2)
print(7 - 2)
print(7 * 2)
print(7 / 2)
print(7 // 2)
print(7 % 2)
print(7 ** 2)
9 5 14 3.5 3 1 49
  • / завжди дає float: 6 / 2 → 3.0.
  • // — ділення без остачі.
  • % — остача від ділення.
  • ** — степінь.

% часто використовують для перевірки парності:

number = 10

print(number % 2 == 0)
True

2Порівняння

Результат порівняння — завжди True або False.

print(5 == 5)
print(5 != 3)
print(5 > 3)
print(5 <= 4)
True True True False

Пастка. = присвоює, == порівнює. if x = 5: — синтаксична помилка.

3Логічні

  • and — True, якщо обидві умови істинні.
  • or — True, якщо хоча б одна істинна.
  • not — перевертає значення.
age = 20
has_ticket = False

print(age >= 18 and has_ticket)
print(age >= 18 or has_ticket)
print(not has_ticket)
False True True

4Скорочене присвоєння

count = 10

count += 5     # same as count = count + 5
count -= 3
count *= 2

print(count)
24

5Порядок виконання

Як у математиці: спершу дужки, потім **, потім * / // %, потім + -. Далі порівняння, і в самому кінці not, and, or.

print(2 + 3 * 4)
print((2 + 3) * 4)
14 20

Якщо є сумнів — став дужки.

5. Рядки

Рядок — це послідовність символів. У кожного символу є номер, тож із рядком можна працювати посимвольно.

[start:stop:step]. Початок входить, кінець — ні.

Пастка. Порядок важить. Якщо першою поставити score >= 60, то для 82 і 95 теж виведеться «Satisfactory».

7. Цикли (for, while)

Цикл повторює блок коду. for — коли відомо, що перебирати. while — коли повторюємо, доки діє умова.

1for і range

Типовий прийом: змінна створюється перед циклом, а в циклі поповнюється.

8. Списки

Список — впорядкований набір значень, який можна змінювати. Найуживаніша структура даних у Python.

1Створення й доступ

models = ["gpt", "claude", "gemini"]

print(models[0])
print(models[-1])
print(models[0:2])
print(len(models))
gpt gemini ['gpt', 'claude'] 3

Індекси та зрізи працюють так само, як у рядках. У списку можуть лежати значення різних типів, навіть інші списки.

2Списки змінюються

На відміну від рядка, елемент можна замінити на місці.

models = ["gpt", "claude", "gemini"]
models[0] = "llama"

print(models)
['llama', 'claude', 'gemini']

3Додавання

numbers = [1, 2, 3]

numbers.append(4)
numbers.insert(0, 0)
numbers.extend([5, 6])

print(numbers)
[0, 1, 2, 3, 4, 5, 6]
  • append(x) — один елемент у кінець.
  • insert(i, x) — на позицію i.
  • extend(items) — усі елементи іншого списку в кінець.

Пастка. append([5, 6]) додасть один елемент — цілий список: [1, 2, 3, [5, 6]].

4Видалення

numbers = [10, 20, 30, 40]

numbers.remove(20)
last = numbers.pop()
del numbers[0]

print(numbers)
print(last)
[30] 40
  • remove(x) — видаляє перше входження за значенням. Якщо немає — ValueError.
  • pop() — забирає останній елемент і повертає його. pop(i) — за індексом.
  • del items[i] — видаляє за індексом.

5Сортування

numbers = [3, 1, 2]

print(sorted(numbers))
print(numbers)

numbers.sort(reverse=True)
print(numbers)
[1, 2, 3] [3, 1, 2] [3, 2, 1]

sorted() повертає новий список. .sort() змінює сам список і повертає None.

Пастка. numbers = numbers.sort() запише в змінну None, список загубиться.

9. Кортежі

Кортеж — це список, який не можна змінити після створення.

1Створення

point = (10, 20)
colors = ("red", "green", "blue")

print(point[0])
print(len(colors))
10 3

Круглі дужки замість квадратних. Індекси, зрізи, len(), in, for працюють як у списку.

2Кортеж не змінюється

point = (10, 20)

point[0] = 15
TypeError

Немає й append(), remove(), sort(). З методів є лише count() та index().

3Кортеж з одного елемента

a = (5)
b = (5,)

print(type(a))
print(type(b))
<class 'int'> <class 'tuple'>

Кортеж робить кома, а не дужки. Без коми (5) — просто число в дужках.

4Розпакування

user = ("Yulia", 28, "Kyiv")

name, age, city = user

print(name)
print(city)
Yulia Kyiv

Змінних зліва має бути стільки ж, скільки елементів у кортежі. Інакше — ValueError.

Саме так працює a, b = b, a і for index, item in enumerate(...).

5Коли брати кортеж, а не список

  • Дані не мають змінюватися: координати, дата, налаштування.
  • Кілька значень, що йдуть разом: (name, price).
  • Потрібен ключ словника або елемент множини. Список там не підійде, кортеж підійде.
visits = {

12. Функції

Функція — це шматок коду з іменем. Написала один раз, викликаєш скільки завгодно разів з різними даними.

1Створення й виклик

2Параметри

    print(f"Hello, {name}!")

name в описі — параметр. "Yulia" у виклику — аргумент, тобто конкретне значення для параметра.

3return

return віддає результат назовні, туди, де функцію викликали.

def add(a, b):
    return a + b

result = add(2, 3)

print(add(10, 5) * 2)
5 30

Після return функція одразу закінчується. Код нижче в ній не виконається.

4return проти print

Це найчастіша плутанина. print показує значення на екрані. return віддає його програмі, щоб із ним можна було працювати далі.

def add_print(a, b):
    print(a + b)

result = add_print(2, 3)

Функція без return повертає None. Тому в result нічого корисного немає.

Правило. Функція рахує й повертає через return. Друкує той, хто її викликав.

13. Обробка винятків (try / except)

Виняток — це помилка під час роботи програми. Без обробки програма падає. З try / except ти сама вирішуєш, що робити далі.

1Що відбувається без обробки

2try / except

try:
    number = int("hello")
except ValueError:
    print("That is not a number")

That is not a number The program keeps running

Python пробує виконати блок try. Якщо стається помилка вказаного типу, переходить у except. Якщо помилки немає, except пропускається.

3Лови конкретний тип

try:
    result = 10 / 0
except ZeroDivisionError:
    print("Cannot divide by zero")
Cannot divide by zero

Пастка. Голий except: ловить усе підряд, навіть друкарську помилку в назві змінної. Програма мовчки робить не те, а ти не бачиш чому. Завжди вказуй тип.

4Кілька типів

    try:
        return int(a) / int(b)
    except ValueError:
        return "Numbers required"
    except ZeroDivisionError:
        return "Division by zero"

print(divide("10", "2"))
print(divide("10", "x"))
print(divide("10", "0"))
5.0 Numbers required Division by zero

Якщо реакція однакова, типи можна згрупувати: except (ValueError, TypeError):.

15. ООП

Об'єктно-орієнтоване програмування збирає дані та функції для роботи з ними в одне ціле — об'єкт.

1Клас і об'єкт

Клас — це креслення. Об'єкт — конкретна річ, зроблена за кресленням.

class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age

yulia = User("Yulia", 28)
oleh = User("Oleh", 31)

print(yulia.name)
print(oleh.age)
Yulia 31
  • __init__ запускається сам, коли створюється об'єкт.
  • self — це сам об'єкт. Через self.name значення зберігається саме в ньому.
  • name, age — атрибути, тобто дані об'єкта.

Назви класів пишуть у стилі CamelCase.

2Методи

Метод — це функція всередині класу. Перший параметр завжди self.

class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def greet(self):
        return f"Hi, I am {self.name}"

    def birthday(self):
        self.age += 1

yulia = User("Yulia", 28)
yulia.birthday()

print(yulia.greet())
print(yulia.age)
Hi, I am Yulia 29

При виклику self не передають: Python підставляє його сам.

Пастка. Забутий self у параметрах методу дає TypeError: takes 0 positional arguments but 1 was given.

3Ти вже користуєшся об'єктами

Рядок, список, словник — це об'єкти вбудованих класів. "text".upper() і numbers.append(4) — виклики методів.

4Об'єкт зі станом

Головна користь класу: об'єкт пам'ятає свої дані між викликами.

class Chat:
    def __init__(self, system_prompt):
        self.messages = [{"role": "system", "content": system_prompt}]

    def add(self, role, content):
        self.messages.append({"role": role, "content": content})

    def count(self):
        return len(self.messages)

chat = Chat("You are a helpful assistant")
chat.add("user", "Hello")
chat.add("assistant", "Welcome!")

print(chat.count())
3

6Наслідування

Новий клас бере все від наявного й додає або змінює своє.

class Model:
    def __init__(self, name):
        self.name = name

    def describe(self):
        return f"Model {self.name}"

class ChatModel(Model):
    def __init__(self, name, temperature):
        super().__init__(name)
        self.temperature = temperature

    def describe(self):
        return f"{super().describe()}, t={self.temperature}"

model = ChatModel("small", 0.2)

print(model.describe())
Model small, t=0.2

super() звертається до батьківського класу.

Ім'я модуля — це назва файлу без .py.

4if __name__ == "__main__"

Під час імпорту Python виконує весь файл згори донизу. Якщо там є print поза функціями, вони спрацюють.

Саме тому from les_4 import ... у твоїх тестах надрукує результати всіх вправ з уроку.

def count_words(text):
    return len(text.split())

if __name__ == "__main__":
    print(count_words("module check"))

Код під цією умовою виконується, тільки коли файл запускають напряму (python text_utils.py). При імпорті він пропускається.

7Сторонні пакети

Усе, чого немає в стандартній бібліотеці, встановлюють через pip:

pip install requests

Після цього import requests працює так само, як з вбудованими модулями. Детальніше — у темі 21.

Пастка. Не називай свій файл так само, як модуль: random.py, json.py, requests.py. Python імпортує твій файл замість справжнього, і все ламається з дивними помилками.
